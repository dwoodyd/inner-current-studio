# Inner Wake

> Wake the inner current. A premium ritual app for emotional alignment, relief, and clarity.

Inner Wake is a dark-first PWA built around short, repeatable rituals — currents you saturate, soften, and align. Designed for calm focus rather than aggressive motivation.

## Stack

- **React 18** + **Vite 5** + **TypeScript 5**
- **Tailwind CSS v3** with a custom design-system token layer (`src/index.css`, `tailwind.config.ts`)
- **shadcn/ui** + Radix primitives
- **Framer Motion** for ambient and transitional motion
- **React Router** for routing
- **TanStack Query** for async state
- **Lovable Cloud** (Supabase under the hood) for auth, database, edge functions, and the Lovable AI Gateway
- **Paddle** for subscriptions and lifetime founder slots

## Local development

```bash
npm install
npm run dev      # vite dev server on http://localhost:8080
npm run build    # production build → dist/
npm run preview  # preview the built bundle
npm run test     # vitest unit tests
```

### Environment

Client env is auto-generated by Lovable Cloud into `.env`, `.env.development`, and `.env.production`. The tracked keys are publishable (`VITE_*`) and safe to expose. See `.env.example` for the required keys.

If you're running outside Lovable, copy `.env.example` to `.env` and fill in the values from your Supabase project (URL, publishable/anon key, project id).

### Edge functions (Lovable Cloud)

Edge functions live under `supabase/functions/<name>`. They deploy automatically on push from Lovable. To run them locally with the Supabase CLI:

```bash
supabase functions serve <name>
```

Server-side secrets (Paddle keys, ElevenLabs, webhook secrets) are managed in **Lovable Cloud → Connectors → Secrets**, not in source.

## Project layout

```
src/
  components/   reusable UI + feature components (CurrentPulse, BottomNav, …)
  pages/        route components
  hooks/        useAuth, useSubscription, useTheme, useDailyLimit, …
  lib/          domain logic (currents, domains, states, AppContext, store)
  integrations/ supabase client (auto-generated — do not edit)
public/         static assets, manifest, service worker, brand images
supabase/       edge functions + config
```

## PWA

- Versioned service worker in `public/sw.js` — network-first for HTML, cache-first for hashed `/assets/*`, stale-while-revalidate for images/fonts.
- Bump `SW_VERSION` in `public/sw.js` to invalidate caches on the next visit.
- The SW is only registered on production hosts; the Lovable preview iframe explicitly unregisters any prior SW to keep edits live.
- Brand splash: `public/apple-splash-1290x2796.jpg` (add device-specific entries in `index.html` if pixel-perfect splash matters).

## Deploy

- **Lovable**: published from the editor → `https://innerwake.lovable.app` and the custom domain.
- **Self-host**: any static host that can serve `dist/` will work. Make sure `/sw.js` and `/manifest.json` are served at the site root with `Cache-Control: no-cache`.
